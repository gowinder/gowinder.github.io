Deploy a Local Stable Diffusion Runtime Environment

midjourney has been quite popular lately, but it has started charging—10 dollars a month, which is more than I can afford—so I switched to the open-source Stable Diffusion. You can deploy it on Google Colab with one click: https://github.com/camenduru/stable-diffusion-webui-colab. However, the free gpu on Google Colab runs out quickly, and although the paid one is cheap, you still have to use it sparingly. If you have a local gpu with more than 8G of VRAM, you can run it on your own computer to save costs; 6G of VRAM should also work—try lowering the resolution and keywords.

This document is based on https://github.com/camenduru/stable-diffusion-webui-colab, and I have added some commonly used models myself. One difference between Stable Diffusion and midjourney is that there are a great many models; choosing a model in the style you want will better generate the effect you want, and it is also more fun to play with. You can pick models on a few commonly used websites:

  • https://huggingface.co/ has many open-source models; just search for stable diffusion. Users there share repositories similar to github repos, and large files can be downloaded directly or via git lfs
  • https://civitai.com/ also has models shared by users, and it is quite intuitive, with sample images, much like instagram—very convenient. Likewise, just search for stable diffusion

Some commonly used stable diffusion websites:

  • https://www.reddit.com/r/StableDiffusion/ — the stable diffusion section on reddit; its tutorials are excellent
  • https://stable-diffusion-art.com has many basic tutorials

Below I will record the deployment process.

Hardware Environment

I have successfully deployed it on proxvox ev 7.3 and ubuntu 20.04, using telsa P4 8G and 3070 8G graphics cards.

Set the Root Folder

google colab uses /content/stable-diffusion-webui, but I put it on zfs locally because the models are quite large and I don’t want to keep downloading them over and over.

1

export PROJ_DIR=/tank/download/ai-relate/stable-diffusion-webui

After setting the $PROJ_DIR environment variable, all downloads will be based on this environment variable.
