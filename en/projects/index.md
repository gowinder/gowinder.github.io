# Projects

Small, single-purpose things I build and run myself.

## [eldertongue.com](https://eldertongue.com)

An Old English dictionary. Form, part of speech, gloss, example, cognates — organised for people actually reading Old English texts rather than browsing an archive. Close to twenty thousand entries, statically generated and served from the edge.

## [massrename.com](https://massrename.com)

A batch file renamer that works in the browser. Stack rename rules, preview every result before anything is touched, then run it once. Built for the cases where "add a prefix" is not enough and a shell script is too much. One-time purchase.
