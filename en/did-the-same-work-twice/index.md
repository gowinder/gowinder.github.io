# Dazed and Confused: I Did the Same Work Twice


Today I was completely out of it — I actually did yesterday's work all over again.  
It's a general-management feature. Yesterday I wrote a CHeroCenter, basically finished. Today I wrote another one called CHeroTender. Surprised, I searched the code, and there it was, that exact same class. Depressing.  
Good thing the class isn't big. A hundred-odd lines of code.
