Mutual References Between Entities in NestJS and TypeORM

20230131-152600

When using nestjs with typeorm, entities that reference each other keep throwing errors; following the official docs, I always ended up with an entity metadata not found error.

The approach that fails

After many attempts, I found it needs to be written like this. Suppose there are two entitys, one UserEntity and one CarEntity, referencing each other. Writing them the following way throws circular import errors.

import {
  Column,
  Entity,
  ManyToMany,
  PrimaryGeneratedColumn,
} from 'typeorm';
import { CarEntity } from './car.entity.ts'

@Entity({ name: 'users' })
export class UserEntity() {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  name: string;

  @ManyToMany(() => CarEntity, (car) => car.id)
  car: CarEntity
}
