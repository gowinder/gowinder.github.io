Notes on Custom ListBox Control Styles and Data Binding

Author published on 2010-11-07

When binding a custom-styled ListBox in Silverlight, there are a few things to watch out for:

  1. The properties specified by ItemTemplate can live in a separate resource file.
  2. The object you bind to, say an ItemTestData, must inherit from the INotifyPropertyChanged interface, and every bound set property you use must call NotifyPropertyChanged(“property name”);
  3. If you want to bind data to the Item object, the custom ItemTemplate style must declare the binding name in its root LayoutRoot.

Mounting a Windows Share Directly with cifs.ko

Author published on 2010-10-27

Found this online, http://myapad.wordpress.com/author/xaueious/

This guy compiled a cifs module for the RK2808 using Archos’s kernel source code

Download it and put it in any directory on the flash, say /flash/cifs.ko

Then run this from the command line

insmod /flash/cifs.ko

That loads the module, and after that you can mount network shares

mount –t cifs –o username=guest,iocharset=utf8 //192.168.0.3/movie /sdcard/movie

I specified the guest user for username, so there’s no password; if there is one, you also need to add password=somekey,

The Joy of Code Generation — Marking My First Integrated Code Generator, DBCodeGen

Author published on 2010-10-06

It suddenly struck me that an engine which supports rapid development needs, besides a good foundation and convenient templates, a complete set of development tools. That toolset should include automated code generation — the way Visual Studio generates an MFC application for you. It saves us a ton of unnecessary work.

Nobody who has used a code generator needs convincing. Back when I was building each system, there was always some repetitive work, and that work was awkward to handle with templates or interface base classes — every time it was copy, paste, then modify, which was a real pain. Then one day a colleague said to me, you can write a program to generate that code. And that’s how, after eating rice for 30 years, I finally learned you can make congee.

Book Review: Marooned in Realtime

Author published on 2010-10-03

http://book.douban.com/review/3801851/

“Marooned in Realtime” is obviously the sequel to “The Peace War”. The style is different — Realtime reads a lot like a detective novel — but I don’t think the way it’s told is all that different. Vinge’s novels always spend a huge amount of the early going laying out the setting, the characters, the clues and so on, so with a Vinge novel you have to get at least halfway through before it becomes impossible to put down. “Realtime” and “The Peace War” are both like that, and so was “A Fire Upon the Deep”, which I read before: the beginning was so dull, I spent days on the first half, reading a bit and stopping, and then I finished the second half in one sitting. The real climax is at the back. It makes you not want to put it down.
