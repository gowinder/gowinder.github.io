两个小站上线了：一个古英语词典，一个批量重命名工具

我一直想验证一个问题：一个人、零预算、不投广告，能不能靠"把一个很窄的需求做到底"做出点东西。

与其想，不如做两个出来看看。这两个站方向完全不同，一个是纯内容站，一个是纯工具站，正好可以当一对对照组。

eldertongue.com — 古英语词典

第一个是 eldertongue.com，一个古英语（Old English）词典站。

做它的原因很朴素：查古英语词义这件事，现有的资源要么是学术机构的老网站，界面停留在 2003 年；要么散落在各种 PDF 和论坛帖子里。而真正需要它的人不少——读《贝奥武夫》的学生、写奇幻小说的作者、单纯对词源好奇的人。

所以我把词条按"词形—词性—释义—例句—同源词"的结构重新组织，做了接近两万个页面。比如 Beowulf 的原文与逐段注释 这种长文本，以前得翻书，现在可以在同一页里点开每个词。

技术上是很轻的一套：静态生成 + Cloudflare 的边缘网络，全球访问都很快，成本几乎为零。

这一站我当成"内容能不能自己长出来"的实验。结论我先给一半：内容做出来不难，让人发现它很难。

massrename.com — 批量重命名工具

第二个是 massrename.com，一个批量重命名工具。

它的来源是我自己的痛点。整理扫描件、剧集、照片的时候，系统自带的批量重命名永远只支持"加前缀 / 改扩展名"这种程度，想要"按拍摄日期重排 + 正则替换 + 序号补零"就得打开命令行写脚本。会写脚本的人不需要这个工具，不会写的人写不出来——中间这块是空的。

所以做成了一个网页工具：规则可以叠加、实时预览改名结果、确认没问题再一次性执行。比如 按拍摄日期和序号整理相册 这种以前要写三行脚本的活，现在拖进去点两下就行。买断制，不订阅。

这一站是"工具能不能卖出去"的实验。目前刚上线，还没有可说的数据。

两件我确认了的事

第一，做出来的成本已经接近零了。 静态站 + 边缘部署 + 一个域名，两个站加起来没有超过一顿饭的钱。真正的成本不在做，在"做之前判断值不值得做"。

第二，写代码不是瓶颈，分发才是。 这两个站让我把过去几年攒的一堆"技术上的正确答案"重新排了一遍优先级：性能、可访问性、结构化数据，这些都该做，但它们的上限是"不拖后腿"。能不能被找到、被信任，是另外一回事。

具体到数字上会更刺眼：站上线两周，Google Search Console 里指向这两个域名的外部链接是 0，Cloudflare 的访问日志里站外来源也是 0。也就是说，不是"排名不高"，是根本还没有人知道它们存在。这一课比任何 SEO 教程都直接。

接下来

我会把这两个站的过程记下来——包括做错的判断。不写成功学，只写"当时怎么想的、后来发现哪里想错了"。

如果你刚好在找这类工具，欢迎试试；有问题直接在这里留言，或者到 X 上找我（@craftstead）。

两个站都是我自己一个人做的，用到的技术栈：Astro / Cloudflare Workers / Cloudflare Pages。
